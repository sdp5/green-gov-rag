## Compliance Notes

### Data Privacy
- GreenGovRAG processes publicly available government documents only
- User queries may be logged for analytics (see Privacy Policy)
- No personal or sensitive data is collected from source documents
- Complies with Australian Privacy Act 1988 (no personal information processing)

### Copyright Compliance
This project complies with Australian copyright law by:
1. Using only openly licensed government data (CC BY 3.0 AU)
2. Providing proper attribution for all sources
3. Generating transformative outputs via RAG (not verbatim copying)
4. Citing original sources in responses
5. Not claiming ownership of government data

### Web Scraping Ethics
When fetching documents, GreenGovRAG:
- Respects `robots.txt` directives
- Implements rate limiting to avoid server overload
- Uses caching to minimize redundant requests
- Only accesses publicly available URLs
